# Example Crate: hello

A minimal Rust library and binary demonstrating a simple greeting function.

Build the example:

```text
cargo build --release
```

Run the example:

```text
./target/release/hello
```

Run tests:

```text
cargo test
```

Generate and view documentation locally:

```text
cargo doc --open
```

The library source is in `src/lib.rs` and the binary entrypoint is `src/main.rs`.
